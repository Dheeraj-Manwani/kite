# Native push-to-talk over VAD

Status: Accepted for v1.

## Context

The user needs an explicit speaking boundary even when another app is focused.

## Options

Voice activity detection; global shortcut toggles; native key down/up hook.

## Decision

Use uiohook with a pure modifier state machine and configurable modifier-only combinations.

## Consequences

Reliable release/cancel semantics support barge-in and spoken approval. The native dependency must be rebuilt and tested, and the hook restarted after sleep.
