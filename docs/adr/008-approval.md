# Deterministic approval summaries

Status: Accepted for v1.

## Context

Users must see an accurate description of the effect before approving a model proposal.

## Options

Model-authored confirmation text; deterministic summaries from schemas.

## Decision

Validate arguments, generate summaries in code, audit decisions, and default sensitive operations to mandatory confirmation.

## Consequences

The model cannot disguise an action with persuasive text. Each tool needs a maintained schema/summary; interruption, timeout, and ambiguous voice decisions must deny.
